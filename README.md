#  Sistema Financeiro Flask

Sistema de gerenciamento financeiro com:

- Flask (backend)
- SQLite (banco de dados)
- Login de usuários
- Dashboard com gráficos
- API de cotação do dólar

##  Tecnologias
- Python
- Flask
- SQLite
- Matplotlib

##  Funcionalidades
- Cadastro e login
- Controle de entradas e saídas
- Dashboard financeiro
- Gráfico automático
